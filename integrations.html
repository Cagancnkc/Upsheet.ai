Notion
Spreadsheet satırlarını Notion veritabanına aktarın.
Bağlantı Ayarları
Notion entegrasyon bilgilerinizi girin
Bağlı değil
📌 Kurulum adımları:
1. notion.so/my-integrations → Yeni entegrasyon oluşturun
2. Internal Integration Secret'ı kopyalayın
3. Hedef veritabanını açın → ... → Bağlantılar → Entegrasyonunuzu ekleyin
4. Database URL'sindeki 32 karakterlik kodu yapıştırın
notion.so/my-integrations adresinden alın → Internal Integration Secret
Notion URL'si: notion.so/workspace/a8aec43384f447ed84390e8e42c2e089?v=...
Kalın kısım Database ID'dir. Veritabanını entegrasyonunuzla paylaşmayı unutmayın.

Webhook Ayarları

Aktif değil
📌 Zapier kurulumu:
Zapier → Yeni Zap → Trigger: Webhooks by Zapier → Catch Hook → URL'yi kopyalayın → Aşağıya yapıştırın

Slack
AI aksiyonlarından sonra Slack kanalınıza otomatik bildirim gönderin.
Slack Bağlantı Ayarları
Incoming Webhook URL'nizi girin
Bağlı değil
📌 Slack Webhook kurulumu:
1. api.slack.com/apps → Create New App → From scratch
2. Sol menüden Incoming Webhooks → Açın (On)
3. Add New Webhook to Workspace → Kanal seçin → İzin verin
4. Oluşturulan URL'yi kopyalayıp aşağıya yapıştırın
Şu formatta olmalı: https://hooks.slack.com/services/...
