Kendi iş akışını kendin yaz.

REST API, webhook ve OAuth 2.0 altyapısıyla Mocksheets'i kendi sistemlerinize tam entegre edin.

REST API Webhook OAuth 2.0 HMAC &Imzalı
Örnek istek
POST https://api.mocksheets.com/v1/export
Authorization: Bearer {token}
Content-Type: application/json

{
  "format": "google-sheets",
  "spreadsheetId": "1BxiMV...",
  "range": "A1:Z100"
}

// Yanıt
{
  "success": true,
  "exportedRows": 247,
  "spreadsheetUrl": "https://..."
}
Güvenli Kimlik Doğrulama
Bearer token ile her API çağrısı doğrulanır. Google OAuth 2.0 ile üçüncü taraf erişimleri izin tabanlı çalışır. Token'lar şifreli saklanır.
Olay Tabanlı Webhook
Tablo güncellemesi, rapor tamamlanması veya dışa aktarım gibi olaylarda anında bildirim alın. HMAC-SHA256 imzasıyla güvenli veri iletimi.
API Dokümantasyonu
Tüm endpoint'ler, parametre açıklamaları ve örnek kodlarla eksiksiz dokümantasyon. Postman koleksiyonu dahil.
